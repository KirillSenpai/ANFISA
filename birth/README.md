# С днём рождения, Аня

Все тексты, картинки и настройки собраны в одном файле: [app/birthday-data.js](app/birthday-data.js).

## Что где менять

### 1. Имя, обращение, подпись

Файл: [app/birthday-data.js](app/birthday-data.js)

- `name` — имя на главном экране
- `petName` — ласковое обращение ("малышка")
- `fromName` — от кого подпись внизу страницы

### 2. Дата дня рождения (отсчёт времени)

Поле `birthdayDateIso`. Если оставить `null` — блока с отсчётом не будет.

Формат:

```js
birthdayDateIso: "2026-09-05T18:00:00+05:00",
```

### 3. Тексты письма

- `shortGreeting` — короткая фраза под именем
- `letterParagraphs` — массив абзацев тёплого письма, можно добавлять/убирать пункты

### 3.1. Замок до дня рождения

Пока не наступит `gateUnlockDateIso` (сейчас `2026-09-11T00:00:00+05:00`),
сайт показывает только экран с замком и обратным отсчётом — дальше пройти
нельзя. Как время наступит, открывается сам.

Для локальной проверки замок можно обойти: в `.env.local` (он в
`.gitignore`, в прод не попадает) строка `NEXT_PUBLIC_SKIP_GATE=1`.

### 4. Подарочный билет на ужин

Блок `dinner` — это не конкретный ресторан, а билет "ужин где захочешь":
место и время выбирает она. Все надписи на билете меняются там же:
`title`, `teaserText`, `admits` ("1 ужин на двоих"), `place`, `validity`,
`holder` / `issuer` (для кого / от кого), `code` (номер билета), `hint`.

### 5. Картинки и гифки

Лежат в [public/img](public/img) (`photo-01..09.png` — милые фото-стикеры без
фона, `gif-01..09.gif` — анимации). Они расставлены прямо в коде — в главах
[app/page.js](app/page.js) (компоненты `HeroChapter`, `LetterChapter` и т.д.,
элементы `<Sticker src="...">`) и в играх [app/games](app/games). Чтобы
поменять картинку, найди нужный `<Sticker src="/img/photo-XX.png">` и замени
путь.

### 5.1. Коллаж общих фото

Блок `collage` в `birthday-data.js`, фото лежат в `public/img/us-01..14.jpg`.
По тапу фото открывается на весь экран с подписью и датой. Чтобы добавить
ещё одно — положи файл в `public/img` и допиши объект в `photos`
(и увеличь `slots`):

```js
{ src: "/img/us-15.jpg", caption: "Подпись 💕", dateLabel: "май 2026" }
```

### 6. Цвета

Файл: [app/globals.css](app/globals.css), самое начало — переменные `:root`.
Розовая палитра завязана на `--pink-1`, `--pink-2`, `--pink-3`, `--pink-deep`.

## Что уже сделано

Сайт устроен как путешествие по главам (не одна длинная страница — экраны
сменяются по кнопке "Дальше"), между смысловыми главами вставлены мини-игры:

1. Начало (герой, имя, отсчёт до дня рождения)
2. Игра "Поймай поцелуйчики"
3. Письмо
4. Игра "Мемори"
5. Коллаж "Наши моменты" (14 фото с подписями)
6. Игра "3 в ряд"
7. Кнопка любви (счётчик, кульминация на 20 нажатий)
8. Игра "Флэппи Аня"
9. Подарочный билет на ужин (место — на её выбор)
10. Финал (подпись, секретное сердечко, "начать сначала")

Каждую игру можно пропустить ссылкой "Пропустить →" — никого не заставляем
проходить через силу. Картинки и гифки раскиданы стикерами по краям панелей:
выезжают при появлении главы, покачиваются, а по нажатию высылают летящие
сердечки/поцелуйчики. Игры и переиспользуемые части — в
[app/games](app/games) и [app/shared.js](app/shared.js).

## Запуск локально

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000)

## Деплой на Vercel

1. Запушить проект в GitHub (папка `birth` в этом репозитории)
2. На [vercel.com](https://vercel.com) — Import Project, указать эту папку
   как корень проекта (Root Directory), если репозиторий содержит несколько
   проектов
3. Deploy — фреймворк Next.js определится автоматически, ничего донастраивать
   не нужно

## Что нужно от тебя

- Ничего обязательного — всё готово. Любой `git push` в `main` сам
  передеплоит сайт на Vercel.
